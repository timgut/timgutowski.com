The work

Things I’ve built, and who for.

I’ve built software and technology for scores of clients: tools that keep workers safe, systems that help kids in foster care find families, and platforms that let organizations run their own websites.

Featured projects

CPWR

Silica-Safe planning tool

Built from the ground up: a WordPress site that helps contractors plan for working safely with silica-producing materials. Its centerpiece is a fully custom planning tool that walks users through a multi-step form and generates a detailed safety plan for their specific circumstances, with links to official guidance. Users can save plans to an account, export them to PDF, or email them.

WordPress · custom plugin · PHP · JavaScript · MySQL

AFSCME

Legislative scorecard

A scorecard that tracks the voting record of every member of the U.S. House and Senate and grades each legislator on alignment with the union’s priorities, backed by a legislator data feed, with IP geolocation landing visitors on their own state’s delegation. Rebuilt for the 2025–2026 edition, launched July 2026.

JavaScript · HTML/CSS · REST APIs · geolocation

Wendy’s Wonderful Kids database

As lead developer, I built and supported the secure web application and database behind Wendy’s Wonderful Kids. Recruiters around the country used it to track their work with each child, and evaluators at Child Trends relied on its reporting to measure what worked.

Custom web application · database · reporting · role-based access
